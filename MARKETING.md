## ICP (Ideal Customer Profile)

### Primary ICP — the agent-native editor
- **Role:** Developer, technical creator, indie hacker, dev-rel, solo founder who makes
  video as an output of other work (demos, explainers, changelogs, reels).
- **Setup:** Mac, Apple Silicon. Already runs an MCP client (Claude Code, Claude Desktop,
  Cursor). Comfortable with `claude mcp add --transport http bay http://127.0.0.1:7333/mcp`.
- **Budget authority:** Self. Personal card, sub-$200 decision, no procurement.
- **Trigger event:** They tried to make a video from a script/dataset with an agent and hit
  the wall — HTML/CSS screenshot pipelines, Remotion builds, or hand-assembling in a GUI
  that the agent cannot see.
- **Current solution:** ffmpeg by hand, Remotion, browser-screenshot pipelines, or giving
  up and editing manually in CapCut/Final Cut.
- **Pain severity:** 7/10. Not bleeding, but repeated and annoying, and they narrate it
  publicly — which is what makes them a distribution channel, not just a customer.
- **Why they matter:** no other editor serves them. This is the only defensible wedge.

### Secondary ICP — the local-first Mac editor
- **Role:** Hobbyist or semi-pro cutting short-form on a Mac.
- **Trigger event:** CapCut paywalled a feature they used, or they object to uploading
  footage to someone else's server.
- **Current solution:** CapCut, iMovie, DaVinci Resolve free tier.
- **Pain severity:** 5/10. Real, but the category is crowded and the switching cost is high.
- **Why secondary:** bay cannot win this on features today (no slip/slide/roll trims, no
  audio mixer, most of the inspector unwritten). Chasing it pre-launch is a losing fight.

### Anti-ICP (do not target)
- Agencies and teams — there is no collaboration, no account, no server, by design.
- Windows users — the build compiles and has never been run (`todo.testing.md`).
- Professional colourists/finishers — bay is nowhere near Resolve and should not pretend.
- Anyone who needs a download today. Until a notarized build exists, sending them to the
  site burns the introduction.

## Personas

### Persona 1: "Dev who ships demos" — the primary ICP, embodied
- **Who:** Solo or two-person team shipping a developer tool. Needs a demo video for every
  release and resents the hours it costs.
- **Core frustration:** "I described the video in one paragraph and then spent four hours
  making it."
- **Language they use:** "MCP server", "render it headless", "burn in the captions",
  "just give me an mp4", "I don't want to open a GUI for this".
- **Objections:** (1) Is this a wrapper around ffmpeg? (2) Will it break my project file?
  (3) It's pre-release, why would I install it now?
- **Decision trigger:** Watching an agent build a real timeline and hand back a real MP4,
  with the tool calls visible.
- **Channels they trust:** GitHub, Hacker News, X/Twitter from people who build things,
  MCP server directories, the docs of the client they already use.

### Persona 2: "Privacy-first cutter" — the secondary ICP
- **Who:** Makes video on a Mac, will not upload client footage anywhere.
- **Core frustration:** Every good tool now wants an account and a cloud round-trip.
- **Objections:** Feature gaps versus what they use now; no download; unknown maker.
- **Channels they trust:** r/videoediting, r/macapps, Mac software blogs, word of mouth.

## Value Prop
- **Core transformation:** Before — describing a change and then performing it by hand in a
  GUI the agent cannot reach. After — describing it and watching it land in the same
  document, on the same timeline, undoable with ⌘Z.
- **The mechanism, which is the actual differentiator:** one Rust engine serves the GPUI
  window and the MCP server. An agent never mutates the project; it submits the same
  `Command` values a human's interaction produces, through one single-writer point. There
  is no second implementation to disagree with the first.
- **Key actions:** import → place on timeline → trim/transform/blend → play → export MP4;
  and the same operations over 21 MCP tools including frame snapshot and render.
- **Activation moment:** first MP4 out of the machine.
- **Aha moment:** an agent-made edit appears on the timeline live, and ⌘Z undoes it.

- **Banned patterns** (binding, from `website/VOICE.md`):

## Competitive Landscape
- **CapCut** — the volume leader; feature paywalls and cloud round-trips are the wedge.
- **Final Cut Pro / Premiere / DaVinci Resolve** — bay does not compete on craft features
  and should not claim to.
- **Descript** — closest on "edit by instruction", but cloud-based and transcript-shaped.
- **Remotion / programmatic video** — closest on "agent makes the video", but it is code
  that compiles to a render, with no timeline a human can take over mid-edit.
- **OpenCut (upstream)** — browser-first, same privacy argument, no native engine, no MCP.
- **Our differentiation, in one sentence:** the timeline and the agent are the same
  document, driven by one engine, on your own machine.
